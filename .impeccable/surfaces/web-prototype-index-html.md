## Surface

- Mode: Operate. A responsive browser-based Athena workspace dashboard.
- Audience: Industry operators and integrators exploring mixed industrial datasets from one open platform.
- Task: Scan synthetic project examples, identify a modality/task, and inspect the proposed task-specific route.
- Content: Synthetic, clearly labeled example rows only; no live models, connectors, or accuracy claims.
- Constraints: Preserve common project navigation and extensible modality plugins. Keep image/video, audio/speech, text/documents, structured/time-series, depth/point-cloud as separate task pathways. No backend framework has been selected.

## Direction contract

THESIS: One shared project and dataset registry makes mixed modalities discoverable without forcing them into one annotation tool. Refuse the image-only dashboard and generic file-manager default.

OWN-WORLD: User-selected Multimodal Signal Board. Matte black rail and table headings, warm off-white work surface, fixed-cell bold labels, amber and red reserved for meaningful state, conventional web navigation and table controls. A split-flap style indicator is the single signature move; no ornamental fake script or faux terminal controls.

STORY: An operator sees what data the workspace can handle, understands each dataset's task and state in plain language, and selects a modality-specific next action. Every sample is labeled synthetic; model and connector status remain honest.

FIRST VIEWPORT: Familiar left rail, all-data dashboard title, modality filters, searchable registry of seven modality examples plus one custom plugin example, visible task/source/review state and preview action columns. A lower panel explains task-specific tools and plugin extension. At narrow widths the registry becomes readable stacked rows, retaining filters and selection.
