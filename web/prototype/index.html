Choose a class, then drag across the image to create a box. Drag inside a box to move it; drag either corner handle to resize it. Select a box and use arrow keys to nudge it 1%; Shift+arrow resizes it. Use Undo/Redo or Ctrl/Cmd+Z and Shift+Ctrl/Cmd+Z while the canvas is focused. History lasts until this dialog closes.
