# Athena SDK

Developer SDK for the Athena open industrial AI standard.

This package ships the versioned Core contracts (`athena_sdk.contracts`),
abstract interfaces for model registries and inference clients
(`athena_sdk.client`, `athena_sdk.registry`), adapter/runtime/domain-pack
interfaces (`athena_sdk.interfaces`), and evaluation harness interfaces
(`athena_sdk.evaluation`).

See the [Athena Open Source README](../../README.md) for the full project
overview.
